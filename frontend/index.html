lyco-sub · 字幕工作台

转录 / 翻译 / 烧录 —— 本地推理，也可用 API 与 CLI 驱动

1. 选择视频

拖入视频文件，或点击选择 支持 mp4 / mkv / mov / wav / mp3

2. 参数

硬字幕会整片重编码。ultra = CRF 18 保画质但文件大； 实测 153MB 源片默认档会压到 3MB。要绝对保真请选软字幕。

给 AI / 脚本用

同一套 core.pipeline，CLI 和 HTTP 行为一致。所有接口都返回稳定 JSON。
# 列出引擎与可用状态 curl http://127.0.0.1:8043/api/capabilities # 提交任务（本地路径，免上传） curl -X POST http://127.0.0.1:8043/api/jobs/by-path \ -H "Content-Type: application/json" \ -d '{"path":"D:/v/demo.mp4","asr_engine":"funasr","burn_mode":"hard"}' # 轮询 curl http://127.0.0.1:8043/api/jobs/<job_id>

CLI

lycosub engines # 看哪些引擎可用 lycosub probe demo.mp4 --json # 探测媒体 lycosub transcribe demo.mp4 --engine funasr --json lycosub translate a.srt --to en --json lycosub run demo.mp4 --engine funasr --burn hard --quality ultra --json lycosub serve --lan # 手机同 WiFi 访问
退出码：0 成功 / 1 运行失败 / 2 用法错误 / 3 引擎不可用 / 4 输入不存在。
